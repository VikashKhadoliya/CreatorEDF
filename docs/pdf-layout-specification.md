# CreatorEDF — PDF Layout & Visual Rendering Specification

This document defines the pixel-level layout specifications, typography, margins, table dimensions, and page-budgeting rules for the three documents generated by CreatorEDF:
1. **EDF Form** (RBI Export Declaration Form Annexure)
2. **Export Invoice** (CBIC / GST-Compliant Commercial Tax Invoice)
3. **AD Code Request Letter** (Bank Formal Request Letter)

---

## 1. Global PDF Quality & Formatting Requirements

- **Page Geometry Standard**: ISO 216 `A4` ($210\text{ mm} \times 297\text{ mm}$ or $595.28\text{ pt} \times 841.89\text{ pt}$).
- **Rendering Vector Fidelity**: All text, tables, and borders must be rendered as vector elements (no rasterized fuzzy screenshots or canvas downsampling). Text must remain searchable and selectable.
- **Font Stack**: Arial / Helvetica family (Standard PDF font with complete fallback to System Sans).
- **Color Palette (Matching Source Styles)**:
  - Primary Dark Text: `#172536`
  - Title / Section Heading: `#243D59`
  - Section Header Background Fill: `#D9EAF7` (Soft Blue)
  - Subtle Alternating Row Fill: `#EEF2F6` (Light Gray-Blue)
  - Dark Accent / Primary Brand: `#1F4E78`
  - Border Lines: `#607286` (Thin $0.5\text{ pt}$ to $0.75\text{ pt}$ solid border)

## 2. Document 1: `EDF Form` (RBI Export Declaration Form)

### 2.1 Page Setup & Margins
- **Page Size**: A4 Portrait ($595.28\text{ pt} \times 841.89\text{ pt}$)
- **Margins**: Top: $18\text{ pt}$ ($0.25"$), Bottom: $18\text{ pt}$ ($0.25"$), Left: $18\text{ pt}$ ($0.25"$), Right: $18\text{ pt}$ ($0.25"$)
- **Printable Width**: $559.28\text{ pt}$
- **Printable Height**: $805.89\text{ pt}$
- **Excel Reference Scale**: $90\%$ scaling over 15 columns (`A` to `O`).
- **Target Page Budget**: 2 Pages (or compact 1-page view for clean single-invoice service filings).

### 2.2 Column Grid Dimensions (15 Columns)
Based on `xl/worksheets/sheet2.xml` column widths:
| Column | Relative Width | Point Width ($559.28\text{ pt}$ Total) | Usage |

| `A` | 3.0 | $16\text{ pt}$ | S.No / Left Margin indent |

### 2.3 Sectional Layout & Box Hierarchy
1. **Title Block (`A1:O1`)**:
   - Text: `Export Declaration Form` (Arial 14pt, Bold, Center, Solid border box, height $26\text{ pt}$).
2. **Section 1: General Information (`A3:O50`)**:
   - Header: `1. General Information:` (Arial 10pt, Bold).
   - Row 1: Left `Type of export: Services`, Right `Form No.: [Number]`.
   - Row 2: Left `Shipping Bill No. & Date: Not applicable`, Right `Mode of Transport / Delivery: Internet`.
   - Row 3: Left `Category of Exporter: [Category]`, Right `AD code: [7-digit AD Code]`.
   - Row 4: Left `IE Code: ... / GSTIN: ... / PAN: ...` (3 lines), Right `AD Name & Address:\n[Bank Name]\n[Branch Address]`.
   - Row 5: Left `Exporter Name & Address:\n[Legal Name]\n[Full Address]`, Right `Mode of Realisation: Others - bank transfer`.
   - Row 6: Left `Consignee Name & Address:\n[Platform Name]\n[Platform Address]`, Right `Port of Loading / Source Port in case of SEZ: Not applicable`.
   - Row 7: Left `Third Party Name & Address: Not applicable\nRelationship: Not applicable`, Middle `Country of Final Destination: [Country]`, Right `Port of Discharge: Not applicable`.
   - Row 8: Left `Name of the AD and AD code, in case of LC / BG: Not applicable / Not applicable`, Right `Date of Let Export Order (LEO): Not applicable`.
   - Row 9: `Description of Goods / Services: [Service Description]` (Full width).
   - Row 10: `Total FOB / Services value in words (INR): [Indian Rupee Words]` (Full width, bold).
3. **Section 2A: Details of Export Value^ of Goods (`A51:O64`)**:
   - Header: `2A. Details of Export Value^ of Goods (This part shall be repeated for each invoice...)`
   - Table containing FOB, Freight, Insurance, Commission, Discount, Other Deductions, Packing. All marked `Not applicable` with empty currency/amounts.
4. **Section 2B: Details of Services Exported (`A66:O87`)**:
   - Header: `2B. Details of Export Value^ of Services` / `2B. Details of Services Exported`.
   - Complete grid table mapping S.No, Buyer Name/Address, Country, Invoice No, Date, Currency, Amount, Net Realisable Value, Contract Ref, Description, SAC Code, Remarks.
5. **Section 3: Applicable for Export under FPO / Couriers (`A89:O98`)**:
   - Left: `Name of the Foreign Post Office / Courier: Not applicable\nNumber & date of Parcel receipts: Not applicable`.
   - Right: Box for `Stamp & Signature of Authorised Dealer`.
6. **Section 4: Declaration by the Exporters (`A100:O120`)**:
   - Header: `4. Declaration by the Exporters (All types of exports)` (Arial 10pt Bold).
   - Legal undertaking text citing FEMA 1999 regulations, with embedded realization deadline date `C38` (e.g. `30-Sep-2026`).
   - Bottom Row: Left `Date: [Date]`, Right `[Signatory Name]\n(Signature of Exporter)`.
7. **Section 5: Space for use of Specified Authority (`A122:O135`)**:
   - Official certification boilerplate for Customs / SEZ / AD / STPI.
8. **Footnotes (`A137:O144`)**:
   - Footnotes 1, 2, and 3 in Arial 8.5pt Italic.

## 4. Document 3: `AD Code Request Letter`

### 4.1 Page Setup & Margins
- **Page Size**: A4 Portrait ($595.28\text{ pt} \times 841.89\text{ pt}$)
- **Margins**: Top: $50.4\text{ pt}$ ($0.7"$), Bottom: $50.4\text{ pt}$ ($0.7"$), Left: $50.4\text{ pt}$ ($0.7"$), Right: $50.4\text{ pt}$ ($0.7"$)
- **Printable Width**: $494.48\text{ pt}$
- **Printable Height**: $741.09\text{ pt}$
- **Excel Reference Scale**: $86\%$ scaling. Single page formal letterhead.

### 4.2 Letter Anatomy
1. **Header**: `REQUEST FOR RBI AUTHORISED DEALER (AD) CODE` (Arial 14pt, Bold, Center, Letter-spaced).
2. **Date Line**: `Date: [Current Date / Declaration Date]` (Arial 10pt).
3. **Recipient Address**:
   - `To,`
   - `The Branch Manager / Forex Department`
   - `[Dynamic Bank Name]` (e.g. `RBL BANK`)
   - `[Dynamic Branch Address]`
4. **Subject**:
   - `Subject: Request for confirmation / provision of RBI Authorised Dealer (AD) Code for Export Declaration Form (EDF)` (Bold 10pt).
5. **Opening Paragraph**:
   - `Dear Sir/Madam,`
   - `I/We, [Exporter Name], maintain a bank account with your branch and receive / intend to receive foreign exchange remittances against export of services / eligible export transactions.`
6. **Account Details Box** (Light gray bordered card):
   - `Account Holder / Exporter Name: [Exporter Name]`
   - `Account Number: [Bank Account Number]`
   - `IFSC Code: [Bank IFSC Code]`
   - `PAN: [Exporter PAN]`
7. **Body Clauses**:
   - Purpose statement citing FEMA regulations and statutory EDF requirements.
   - Centralized forex branch routing clause (if account branch does not handle forex).
8. **Enumerated Confirmation Items**:
   - `1. RBI Authorised Dealer (AD) Code: ______________________________________________`
   - `2. Name / Address of designated AD / Forex Branch: ________________________________`
   - `3. SWIFT / BIC Code (if applicable): ______________________________________________`
   - `4. Confirmation that the above AD Code may be quoted in the EDF for export proceeds...`
9. **Closing**:
   - `The information is required for regulatory documentation... Kindly provide the above details by email / stamped letter, as applicable.`
   - `Thank you.`
   - `Yours faithfully,`
   - `Mobile: [Mobile Number]`
   - `Email: [Email Address]`
   - `Signature: ______________________________ ([Signatory Name])`

## 5. Client-Side Generation & Preview Architecture

- **Rendering Engine**: Client-side PDF generation using `@react-pdf/renderer` or `jspdf` + `jspdf-autotable`.
  - Zero server dependency, preserving complete user financial privacy.
  - Generates binary `Blob` directly in the browser.
- **In-Browser Interactive Preview**:
  - Embedded `PDFViewer` modal / tab allowing instantaneous visual inspection before downloading.
- **Export Options**:
  - `Download EDF Form (PDF)`
  - `Download Export Invoice (PDF)`
  - `Download AD Code Letter (PDF)`
  - `Download Complete Compliance Packet (ZIP)` (Bundling all three PDFs + JSON backup using `JSZip`).
